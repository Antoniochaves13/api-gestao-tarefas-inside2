API de Gestão de Tarefas - Backend

Problema: Criar API completa CRUD para Inside Systems

Stack: Node.js, Express, MongoDB Atlas, Mongoose, NoSQL, SQL, REST

Endpoints: GET /tarefas, POST /tarefas, PUT /tarefas/:id, DELETE /tarefas/:id

Exemplo SQL: SELECT status, COUNT(*) as total FROM tarefas GROUP BY status;
